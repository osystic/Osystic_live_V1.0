# OSYSTIC P1/P2 Source Release Manifest

This checkpoint contains the complete Next.js source tree from the P0 Careers baseline plus the finalized P1/P2 source changes, public assets, `.env.example`, existing `package-lock.json`, and QA/release documentation.

Included P1/P2 additions include the three capability pillar routes, focused Enterprise RAG and AI Reliability services, service alias redirects, sitemap consolidation, reusable pillar/structured-data components, responsive finalization, compact footer density polish from localhost visual QA, content-risk wording cleanup, and the dependency-independent static QA script.

Excluded from delivery: `node_modules`, `.next`, private `.env` files, caches, coverage output, local credentials, temporary logs, OS metadata files, and stale generated responsive build/audit output.

This is a source checkpoint, not proof of a production deployment. Run the exact dependency-backed/local acceptance commands in `QA_REPORT.md` before release.
